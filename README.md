# 托管管理后台

平台管理员管理全部机构、创建机构管理员账号并分配机构。机构管理员在自己的机构内启用教师和家长登记码、审核登记申请、分配教师、编辑学生资料及管理家长绑定。后台与小程序共用后端数据库。

## 本机运行

1. 在同级目录 `tuoguan_back` 执行 `npm ci` 和 `npm run admin:dev`。
2. 在当前目录执行 `npm ci` 和 `npm run dev`。
3. 打开 [本机管理后台](http://127.0.0.1:5173/)，使用 `tuoguan_back/data/dev/admin-login.txt` 内的本机凭据登录。

## 办理登记

从左侧菜单进入「人员管理」，在侧栏底部切换当前机构。平台管理员可在同一区域进入「后台账号」。

1. 展开机构标题下方的「登记码」，自动生成并展示教师、家长二维码。卡片提供「下载图片」和「下载 PDF」，两种文件均在二维码上方注明用途。接入微信发码时可选择正式版、体验版或开发版。
2. 在「审核」开通教师或核对家长资料。家长申请选定已有学生后，审核通过即绑定；核实为新生也可在审核时建档。教师可以先从「教师 → 新增教师」建档，扫码登记后在审核中选中该档案，审核通过即关联微信。
3. 在「学生」筛选待分配档案，逐条或批量指定启用教师。停用或删除教师时，其名下学生转为待分配。
4. 在「家长」查看每位家长绑定的孩子，可以单独解绑一个孩子，也可以删除家长并解除他在本机构的全部绑定。
5. 在「教师」或「学生」列表操作栏删除档案，历史作业与反馈会保留。状态筛选中的「已删除」可查看移出名单的教师和学生。
6. 平台管理员在机构页顶部可以删除机构，删除后机构码和机构内访问权限失效，历史数据保留。
7. 在教师列表操作栏的「权限设置」中开启「登记审核」，可授权该教师在小程序内处理本机构的教师、家长登记。权限默认关闭。
8. 在学生列表点击「作业情况」，按日查看家长提交的作业和照片，并保存或修改整体反馈。网页与小程序使用同一份记录。停用或已删除的档案可查看历史作业。

## 部署

执行 `npm run build` 生成 `dist/`。启用后端管理接口并设置 `ADMIN_WEB_DIR` 后，后台挂载在同一 HTTPS 域名的 `/admin/`。完整配置见 [后端部署说明](../tuoguan_back/README.md)。
